# SIGMA fp — ISO / 增益處理完整反編譯

fp Ver.5.02,感光元件 **Sony IMX410**(fp L = IMX455,機制相同暫存器不同)。位址 base 0xC0000000,decomp `out/decomp/full/blk_c0X.c`,ROM 讀自 `out/seg0_c0000000.bin`(offset=VA−0xC0000000)。信心逐節標。
感光元件物件 `0xC343B588`,port vtable `0xC0B5FCC0`。I2C helper `FUN_c0322c70(reg,val)`(16-bit reg + 8-bit data,Sony 格式)。

═══════════════════════════════════════════════════════════════
## ★ 雙原生 ISO(dual native ISO)— 信心:很高
═══════════════════════════════════════════════════════════════
IMX410 有**雙轉換增益**(HCG/LCG = high/low conversion gain)。切換決策 `XC_ImageSensorIMX410__v30 @c03239c8`,回傳 1=HCG(第二原生)、0=LCG,存感光元件物件 `+0x34`。寫暫存器 `XC_ImageSensorIMX410__v10 @c0323818`:

| 暫存器 | LCG(0) | HCG(1) | 意義 |
|---|---|---|---|
| **0x05E1** | 0 | 1 | 轉換增益選擇 FDG_SEL |
| 0x05A6 | 0x29 | 0x2A | 黑階/偏壓微調 |
| 0x05A8 | 0x27 | 0x29 | 黑階/偏壓微調 |

**兩個原生 ISO(切換點,模式相依,硬碼)**:
| 模式 | 低原生(LCG) | 高原生(HCG 切換) |
|---|---|---|
| **拍照 + 標準/8/10-bit 影片** | **ISO 100** | **ISO 640** |
| **12-bit CinemaDNG 影片** | **ISO 100** | **ISO 3200** |

- 判定:`v30` 依 `param_2[3]`(gain_state/讀出模式)分支;門檻經 `FUN_c00b8860(0x280=640 / 0xc80=3200)` 映射。640/3200 是硬碼(blk_c03.c:24678/24683)。
- **12-bit 刻意讓 LCG 撐到 ISO 3200 保留動態範圍**;其餘 640 就切。
- **拍照和標準影片共用 100/640 路徑**(沒有獨立 Still_GainMode);live-view 切換點是 per-unit OTP 校準(`sensor+0x84`,不在 ROM)。
- **強制 LCG**:shell `imager high_gain_off 1`(`FUN_c0320ca0` 寫物件 `+0x37`;字串 "high gain force off")。或 `i2c w` 直寫 `0x05E1`。

**⚠️ 另一條高類比讀出路徑(別混淆)**:當**類比 code ≥ 0xDFD(3581,≈18dB≈ISO 800)** 時,`v10` 另切一組暫存器(`0x05E2=1`、`0x041F=0x0E/0x1D`)—— 這是高類比增益讀出模式,**不是**主雙原生切換(主切換看 ISO 640/3200 的 v30)。

## 增益組成(ISO → 類比/轉換/數位)— 信心:很高
═══════════════════════════════════════════════════════════════
核心 `XC_ImageSensorIMX410__v8 @c0323580`。以 dB 計算(常數 `DAT_c03239b8=4095.0`、`DAT_c03239c0=100.0`):
```
dB          = 20·log10(relative_gain% / 100)      # relative_gain 是百分比,100 = 1.0× = base
linear_gain = 10^(dB/20)
analog_code = round(4095 · (1 − 1/linear_gain))   # 12-bit
 ⇒ linear_gain = 4095 / (4095 − analog_code)      # Sony 式(注意是 4095 不是 1024)
```
1. **類比增益**(感光元件暫存器 `0x5C/0x5D`,另一路 `0x3D/0x3E`+`0x3F/0x40`):code 用到校準上限 `sensor+0x68`(max analog dB)。
2. **轉換增益**(`0x05E1`):選 HCG 時 dB 減 `sensor+0x7c` offset,以第二原生為新基準。
3. **數位增益**:只在 dB 超過類比上限才補 → `digital = digital_base · 10^((dB−maxAnalog)/20)`,base=**100(1.0×)**,`FUN_c0312f18` floor 100。`AeDigitalGainBase::v0 @c020cc10` 裝這個 unity。shell `imager set_gain_state 8` 關數位。

**abs_gain 打包**(`FUN_c0312f18`):`[15:0]=analog_code`、`[30:16]=digital_gain%`。
- 每檔 = **+6.02 dB**(ISO 加倍);1/3 檔 ≈ +2.008 dB(Sv 步 341/1024 stop)。
- ⚠️ max-analog 上限(`sensor+0x68`)、HCG dB offset(`+0x7c`)、數位 base(`+0x70`)、live-view 切換(`+0x84`)全是 **per-unit OTP 校準**(讀自感光元件校準 flash,`FUN_c03344b0` blob `FUN_c0355b98(...,0xc00,0x1fe,...)`),ROM 預設是 0 → 要精確值得 dump。
