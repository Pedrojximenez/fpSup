fpGyroSup r23：保留 2,500 Hz，以四位數查表取代三軸除法

這不是降頻版，也沒有抽幀。r23 以 r22 為底，將每列三軸的十進位轉換改成
0000--9999 查表，並在一次呼叫內完成 X、Y、Z 與逗號。timestamp、雙緩衝、
64 KiB 寫卡、5 ms 讓步、錄影鎖、關機保護及 JSON 流程都沒有改。

請盡量重複 A001_015 的負載方式：
1. 開機等到 fpSup!。
2. 錄約 60 秒；前 30 秒保持相機穩定。
3. 後 30 秒持續手持移動，幅度接近 A001_015，但不要撞擊相機或讀卡介面。
4. 正常停止，等鎖解除後可接錄下一段，或直接正常關機等待整套任務完成。
5. 相機正常關閉後，把卡放回讀卡器並說「讀卡」。

r22 A001_015 對照基準：
- 全片 156,584 / 160,364 筆，完整率 97.642862%，缺 3,780 筆。
- 前 30 秒每五秒區間約保留 99.968--99.984%；主要損失在高動態後半段。
- 大缺口為 528.811、200.628、463.363、308.744 ms。
- 高動態區每列平均曾升到約 40.81 bytes。

主要驗收：
- 每段 DNG 編號連續，GCSV 與 JSON 完整，本版不會新增 GYR。
- GCSV 時間戳單調、正常間隔 400 us，所有列皆為完整七欄數字。
- 首要比較後 30 秒是否消除整批 200--529 ms 缺口。
- 完整率應明顯高於 97.642862%；理想目標是回到或超過 r17 的 99.817637%。
- 整套任務完成前，下一段錄影與關機保護仍須有效。

立即停止測試的條件：
- 錄影自行中止、畫面凍結、卡燈或錄影燈異常長亮。
- 停止後超過約 15 秒仍不能錄下一段或正常關機。

不要混合安裝 r22 與 r23 的啟動檔；三個檔案必須來自同一個資料夾。
