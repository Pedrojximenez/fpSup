fpGyroSup r15：GCSV-only 邊錄邊生成測試

這版不會建立 GYR。錄影期間由原有 writer 把固定 RAM buffer 直接轉成
GCSV；每累積約 32 KiB 完整文字列才寫卡一次。停止後只排空 GCSV 尾端並
生成 JSON。

第一輪測試：
1. 開機等到 fpSup!。
2. 先錄 10～15 秒並正常停止，確認相機沒有凍結。
3. 再錄約 60 秒；留意是否像先前一樣在約 20 秒被強制停止。
4. 正常停止後立刻嘗試開始下一段，記錄大約多久才接受錄影。
5. 第三段錄 10～15 秒，停止後立即使用正常關機。
6. 相機自行關閉後，把卡放回讀卡器並說「讀卡」。

立即停止測試的條件：
- 錄影自行中止、畫面凍結、卡燈異常長亮。
- 停止後超過約 15 秒仍不能錄下一段或正常關機。
- 若凍結，不要再錄；直接把卡交回讀取。

驗收：
- 每段 CINEMA 資料夾內都有同名 GCSV 與 JSON。
- 卡上沒有本版建立的 GYR。
- GCSV 可解析、時間戳連續，長度涵蓋完整錄影且沒有樣本缺口。
- 第二段只能在第一段 JSON 完成後開始。
- 正常關機沒有截斷最後一段 GCSV／JSON。

r14 是獨立回退基準；不要把 r14 與 r15 的檔案混合安裝。
