fpGyroSup r26：三槽 logger 隱藏邊界測試

r25 已在拔電池冷啟動後測過：A001_021 的 CinemaDNG 正常連續，但沒有產生
GCSV／JSON。這表示問題不是舊 task、back-pressure probe 或 PGEN；r25 的
常駐 logger 尾端越過 0xC072EF00 是目前最具體的差異。

r26 不改三槽 queue、GCSV 計算或寫卡策略，只把常駐程式縮小 64 bytes。
現在尾端位於 0xC072EEE4，低於疑似邊界 28 bytes；PGEN 與成功的 r23 完全
相同。

這輪只錄一段約 10 秒：
1. 請先拔電池或確認相機已完整冷啟動。
2. 放入卡片開機，等到 fpSup!，再等約 3 秒。
3. 錄 10 秒後正常停止，不必刻意大幅晃動。
4. 等錄影鎖解除後正常關機，再把卡放回讀卡器並說「讀卡」。

唯一驗收是同一段 CinemaDNG 是否同時出現 GCSV 與 JSON：
- 若兩者出現：可確認 r24/r25 踩到常駐程式的隱藏邊界，三槽流程可繼續。
- 若兩者仍都沒有：再查三槽 logger 的啟動行為，不再動 PGEN。

本版不會新增 GYR。三個啟動檔必須全部來自這個資料夾。
