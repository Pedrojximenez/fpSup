fpGyroSup r25 three-slot / r23-PGEN isolation build
Build date: 2026-08-31
Camera/firmware: SIGMA fp Ver.5.02
Build type: release AutoRun, no USB shell

Purpose:
- r24 produced three continuous CinemaDNG clips (A001_018, A001_019 and, after
  a battery-out cold boot, A001_020) but created no GCSV or JSON at all.
- The cold boot disproved the initial stale-task hypothesis.  Because no GCSV
  directory entry was created, the failure happens before triple-buffer
  back-pressure can be exercised.
- r25 isolates the two r24 variables instead of adding another unproven loader
  change: keep the ordered three-slot logger, remove the back-pressure probe,
  and restore the exact r23 PGEN binary.

Configuration:
- Three fixed 32 KiB raw slots; writer consumes the lowest READY sequence.
- r23 four-digit lookup, fused gyro formatter, 64 KiB complete-line writes and
  5 ms pacing are unchanged.
- No back-pressure counters or JSON diagnostic object in this build.
- PGEN.BIN is byte-for-byte identical to successful r23, SHA-256
  3e729c0babe1fa0c9dad22e3e7292c8412d30f931b0717fe10c30f6696c0fcea.
- This GCSV-only build creates no GYR.

Interpretation:
- If r25 creates GCSV and JSON, r24's PGEN/probe addition caused the startup
  regression; the three-slot logger is viable.
- If r25 still creates neither file, the regression is in the enlarged
  three-slot resident logger or its code layout, not PGEN.

Verification:
- All 56 format, queue, layout, lifecycle and safety tests pass.
- Resident logger is 3,776 bytes, ending at 0xC072EF24 with 144 bytes before
  the fixed parking stub.
- PGEN pool code is 47,736 bytes and 47,752 bytes on card, exactly r23.
- AutoRun is byte-identical to r23/r24; VSHL contains the three-slot logger.
- Experimental isolation build; not fp-gyro-sup-v1.1.
