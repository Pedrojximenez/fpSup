fpGyroSup r22：以精確 r17 為底，只展開每列的加速度文字複製

r21 的 16 位乘法已完全移除。r22 的數值計算、timestamp、雙緩衝、64 KiB
寫卡、5 ms 讓步與 lifecycle 都是 r17；唯一差異是把每列已快取的加速度文字
分成四 byte 一組讀取。目的位址仍逐 byte 寫入，格式與精度完全相同。

為了能和 A001_014 直接比較，請盡量重複同一種測試：
1. 開機等到 fpSup!。
2. 錄約 60 秒；前 30 秒保持相機穩定。
3. 後 30 秒持續手持移動，幅度接近上次測試，但不要撞擊相機或讀卡介面。
4. 正常停止，確認鎖解除後可錄下一段，或直接正常關機等待 GCSV/JSON 完成。
5. 相機正常關閉後，把卡放回讀卡器並說「讀卡」。

r21 A001_014 對照基準：
- 全片 150,624 / 153,614 筆，完整率 98.053563%。
- 前 30 秒只缺約 16 筆；高動態的 30--60 秒約保留 96.03%。
- 主要缺口為 320.972、181.349、41.006、320.961、322.996 ms。
- 高動態時每列長度由約 34 bytes 增至 38--40 bytes。

主要驗收：
- 每段 DNG 編號連續，GCSV 與 JSON 完整，本版不會新增 GYR。
- GCSV 時間戳單調、正常間隔 400 us，所有列皆為完整七欄數字。
- 首要比較後 30 秒是否不再出現約 321 ms 的整批缺口。
- 全片完整率應明顯高於 98.053563%；目標至少回到 r17 的 99.817637%。
- GCSV/JSON 整套任務完成前，下一段錄影與關機保護仍須有效。

立即停止測試的條件：
- 錄影自行中止、畫面凍結、卡燈或錄影燈異常長亮。
- 停止後超過約 15 秒仍不能錄下一段或正常關機。

不要混合安裝 r21 與 r22 的啟動檔。
