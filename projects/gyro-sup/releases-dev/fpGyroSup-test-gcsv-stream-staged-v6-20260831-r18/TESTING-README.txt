100.440 ms 的缺口。r18 不再讓卡片寫入占住來源 raw 緩衝：每塊資料先完整

測試流程：
1. 開機等到 fpSup!。
2. 先錄 10～15 秒並正常停止，確認相機沒有凍結或自行停止。
3. 錄約 60 秒；停止後，在錄影鎖解除時立即接錄第二段 10～15 秒。
4. 第二段停止後立即正常關機，確認相機會等 GCSV/JSON 完成再關閉。
5. 若以上正常，再錄約 120 秒，檢查長時間是否仍無累積落後。
6. 相機正常關閉後，把卡放回讀卡器並說「讀卡」。

立即停止測試的條件：
- 錄影自行中止、畫面凍結、卡燈或錄影燈異常長亮。
- 停止後超過約 15 秒仍不能錄下一段或正常關機。
- 若凍結，不要再錄；直接把卡交回讀取。

主要驗收：
- 每段 CINEMA 資料夾都有同名 GCSV 與 JSON，本版不會新增 GYR。
- GCSV 時間戳單調，正常間隔為 400 us，且不應再出現超過 10 ms 的缺口。
- 一分鐘片段應接近 150,000 筆，完整率以 100% 為目標。
- DNG 編號連續，錄影不會因 sidecar 寫入而自行停止。
- GCSV/JSON 整套任務完成前，下一段錄影與關機保護仍須有效。
