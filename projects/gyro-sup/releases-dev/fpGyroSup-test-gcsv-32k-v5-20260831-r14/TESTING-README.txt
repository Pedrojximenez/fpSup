fpGyroSup r14：32 KiB GCSV 寫入 A/B 測試

這版只把 GCSV 單次寫入從 16 KiB 加倍到 32 KiB；每次寫完仍讓步 5 ms。
r13 的快速十進位格式器、native MovieSaving 鎖與 GYR -> GCSV -> JSON 順序不變。

測試：
1. 開機等 fpSup!。
2. 錄製一段約 60 秒 CinemaDNG，停止後立刻嘗試開始下一段。
3. 記下大約幾秒後相機接受第二段。
4. 第二段錄 10～15 秒並停止，使用正常關機。
5. 相機自行關閉後，把卡放回讀卡器並說「讀卡」。

立即停止測試的條件：
- 停止錄影時凍結、卡燈異常長亮，或超過約 15 秒仍未解鎖。
- 相機若凍結，不要再錄；直接把卡交回讀取。

驗收：
- 兩段 GYR dropped=0、error=0。
- GCSV 與 GYR 逐列一致，JSON 完整。
- 第二段只在第一段 JSON 完成後建立。
- 正常關機不截斷第二段 sidecar。

若 r14 仍只比 r13 快不到約 2 秒，就不再增加寫入大小，改查 F_WRITE 本身與
檔案物件／快取路徑。
