fpGyroSup r36: 1250 Hz 抗混疊降採樣 + 稀疏加速度計 (測漏針)

安裝：把 AutoRun.txt、VSHL.BIN、PGEN.BIN 覆蓋到 SD 卡根目錄（三個都要換整套，
勿與其他版本混用）。

測試流程：
1. 拔電池冷開機，等 fpSup!。
2. 先錄 20～30 秒，正常停止並等 SD 鎖解除。
3. 確認可再次錄影後，錄 5～10 分鐘，正常停止。
4. 正常關機後讀卡。

每段檢查（重點是漏針，不是 JSON）：
- GCSV 存在、可被 Gyroflow 讀入。
- gyro 相鄰時間戳應相差 800 us（1250 Hz），不再是 400。
- 有加速度的列是 7 欄（t,gx,gy,gz,ax,ay,az），其餘是 4 欄（t,gx,gy,gz）。
  4 欄列結尾必須是 gz，後面沒有逗號。
- 用 ceil(最後時間戳 / 800) 當應有列數，算完整率；長片應接近 100%，
  尤其不該再出現先前每個 raw block 後 0.7～2.1 秒的大缺口。

判讀：
- 若長片 GCSV 完整率明顯回升、且 DNG 沒有自行停錄 → 降採樣方向成立。
- 若某段有 GCSV 但沒有 JSON：那是已知的 width=0 另一條線，與本版無關，
  用 GCSV 本身判漏針即可。
- 若畫面凍結或停止後 SD 燈長亮：立刻停止，拔電池後讀卡（GCSV 是 hook 寫的，
  凍結後仍在），把最後一段 GCSV 尾端交回。

本版是實驗診斷版，非正式 v1.1。
