fpGyroSup r10 原生 WaitEncoding 整段鎖測試

一次任務的完成順序固定為：

CinemaDNG 結束 -> GYR 關檔 -> 進入 WaitEncoding -> GCSV -> JSON -> 解鎖

這版只修錄影／關機鎖，不改 GCSV 效能：
- GCSV 二進位與 r9 逐位元相同。
- 仍是 16 KiB 寫入與每段 5 ms 讓步。
- 不啟用開機掃描或復原補寫；卡上舊的 052／053 不會自動補齊。

測試：
1. 開機等 fpSup!。
2. 錄製 30～45 秒並停止。
3. 停止後一兩秒內立刻按錄影鍵，可再按數次：預期不會建立新片段，直到同片
   GCSV、JSON 都完成才恢復錄影。可順便計時「停止到重新可錄」需要幾秒。
4. 解鎖後錄第二段 30～45 秒並停止，立刻正常關機：預期相機等待 sidecar 完成
   才關機。請勿強制斷電。
5. 把卡放回讀卡器並說「讀卡」。

僅供 SIGMA fp Ver.5.02 測試。這是無 USB shell 的 release AutoRun。
