# fp 機內融合：幾何判運動方向，DFD 估離焦量

日期：2026-09-27。依使用者澄清修訂：沿用其他專案驗證過的幾何對焦經驗，利用機內臉部辨識與 AAT，**先有一次可靠合焦，再用幾何判主體相對相機的接近／遠離；若 DFD 可用，再由 DFD 提供離焦量與所需鏡頭位移**。舊專案以幾何估距的能力保留作比較與條件式備援。幾何從後續選配提升為現在的主線。

這是本次確立的模組分工，尚未宣稱機內方向器、DFD 或融合控制已完成。本文只整理程式與設計，未操作相機。

## 1. 舊方案與新分工

| 模組 | 舊幾何專案 | 新機內主線 |
|---|---|---|
| 臉／主體追蹤 | 提供同一主體的尺寸與信心 | 機內 face／AAT 提供主體連續性、可靠尺度與採用 ROI；各來源分開標記 |
| 幾何 | 尺寸經校準曲線換焦點位置，再預測延遲後的位置 | 優先輸出接近／遠離／近似靜止／未知，以及相對變化率與信心；先不要求絕對公尺或 motor target |
| DFD | 舊研究曾比較模糊／曲線估計，不能當成已成功機內 DFD | 條件式加入：估目前的殘餘離焦量／目標焦點區間，再依鏡頭校準換所需位移 |
| 原廠 CDAF | 可作光學校準與確認 | 確認當前合焦、修正誤差並作信心不足時的搜尋；原廠 manager 保持鏡頭控制權 |

DFD 要回答的是「現在焦平面相對目標還差多少」，未必需要先求「主體距離相機幾公尺」。幾何的接近／遠離也不是畫面中的左右位移。這兩項量的單位與時間都應分開。

## 1A. 必要前提：首次合焦建立錨點

本方案先改善**合焦之後的追焦**。只知道物體正在接近，不能知道一台剛啟動、焦點任意的相機應把鏡頭往哪裡修正；嚴重失焦時，face／AAT 也可能無法提供可靠尺度。

1. **尚無錨點**：由原廠 CDAF 完成首次合焦。幾何可旁路觀察，但不據此直接控制鏡頭。
2. **建立錨點**：記錄同一主體／尺度來源、合焦時尺度 `s0`、鏡頭位置 `p0`、時間、光圈與成像模式，以及合焦確認來源。一次合焦可建立追焦基準，不等於建立完整的尺度→公尺／鏡頭位置曲線。
3. **有效追焦**：幾何提供運動趨勢；DFD 若可靠，估目前殘餘離焦；CDAF 保留確認與修正。後續只有新的光學合焦確認才能更新錨點，不能因鏡頭命令完成就自行宣布合焦。
4. **錨點失效**：換主體、無法確認尺度來源連續、模式／鏡頭改變、過久遮擋或光學證據矛盾時撤回幾何控制，交回原廠重新取得。短暫遺失可在已驗證期限內保留候選錨點，但不無限外推。

**不需絕對距離校準 ≠ 不需首次合焦。** 理想條件下單看尺度趨勢可以描述接近／遠離，但要把它變成可靠的修焦建議，本輪方案要求上述合焦錨點及控制狀態。DFD 只有另行證明能在無錨點時獨立判前後焦，才可能改善冷啟動；僅有離焦大小不夠，不能預設這個能力已成立。

## 2. 可直接沿用的舊方法

在**同一主體、相同尺度定義、投影／姿態條件足夠穩定**時，以正規化線性尺寸 `s` 表達主體在畫面中的大小；其倒數 `q = 1/s` 隨相對深度增加而增加。短時間窗對 `q(t)` 擬合斜率：

- 明確為負：主體相對相機接近。
- 明確為正：主體相對相機遠離。
- 可分辨且接近零：近似靜止。
- 訊號不足、變形或來源切換：未知，不強行分類為靜止。

只估影像尺度的運動趨勢不需要先知道主體的真實尺寸，也不必先有尺寸到鏡頭位置的完整校準；**用於修焦仍遵守前節的首次合焦要求**。若使用框面積作尺度，需先確認框語意，不能把面積直接當線性寬度；可研究 `sqrt(area)`，不是無條件替代。

舊 [predict.py](/Users/dido/Developer.localized/sigma-fp-bridge/focus-ai/focus/predict.py:142) 已有短窗擬合、相對殘差、斜率標準誤及信心縮減；但 `Predictor.predict()` **先呼叫 `curve.position()`，無有效曲線即退出**。新機內方向器應抽出尺寸序列與斜率估計，解除對絕對位置模型的依賴，不能只是原樣搬入舊 predictor。

舊 0.25 s 視窗、5 個樣本、影像延遲與 motor speed 是舊系統條件，不直接當機內常數。方向版本需要重新量：可用來源頻率、方向翻轉延遲、靜止誤觸發、遺失及慢動作的有效覆蓋率。

舊 [subject.py](/Users/dido/Developer.localized/sigma-fp-bridge/focus-ai/focus/subject.py:1) 已區分直接量測與由其他線索推算的尺寸，並處理尺寸正規化與來源比例。重用時保留 `measured / inferred`，只有可信直接量測更新來源間比例；不能拿自己的預測回頭當新真值。

歷史幾何估距、跨場次誤差與未能重現的精確數字，仍按 [開發盤點](/Users/dido/Developer.localized/SIGMAfp_re/projects/fp-af-assist/notes/FP_AF_DEVELOPMENT_STATUS_2026-09-27.md) 記錄。使用者已有的驗證是本輪方法基礎；機內 face／AAT 的尺寸來源不同，需確認可比性，而不是把方法重新降回沒有基礎的構想。

## 3. Face 與 AAT 要各自驗證尺度語意

**臉部框／landmark：**優先保留同一人的尺度與姿態／quality。轉頭、表情、部分遮擋會改變投影尺寸；fp 有哪些可靠欄位要以原始結果確認，不能假設舊外部偵測器的 landmark、yaw 或人體偵測全部在機內存在。

**AAT：**先驗證它能否提供穩定的物體尺度，而不只是位置和顏色追蹤。fp 的 `C05B2DC0` 會自動調整框尺寸，`C05C3D28` 又在送 AF 前重塑框；顯示框、搜尋窗、追蹤結果框、AF ROI 必須分開。框自己放大不等於物體接近。

直接程式支持的界線：原始 face record 的 size 由 [C05AAFF8](/Users/dido/Developer.localized/SIGMAfp_re/out/decomp/full/blk_c05.c:131621) 解析；AAT 半軸來自 [命中點共變異數擬合](/Users/dido/Developer.localized/SIGMAfp_re/out/decomp/full/blk_c05.c:136224)，[GetResult](/Users/dido/Developer.localized/SIGMAfp_re/out/decomp/full/blk_c05.c:139568) 又可能走另一份處理狀態再轉換。`model+0x0C` 是 hits 映射出的 confidence，`+0x0D` 是 `100×axis1×axis2/maxAxis²`，不是前景命中密度；兩者都不直接代表尺度可信度。[欄位計算](/Users/dido/Developer.localized/SIGMAfp_re/out/decomp/full/blk_c05.c:139889)

初版可讓 face 提供可靠尺度，AAT 維持主體位置／連續性；AAT 尺度通過固定距離、已知前後移動與模型更新對照後，再把它納入方向估計。face 消失或交棒時，沒有已驗證的來源比例就重新建立短窗，不能把兩種尺寸直接串接。

必須有三組對照：

1. 固定鏡頭焦點，物體已知接近／遠離：驗方向與翻轉延遲。
2. 物體距離不變，鏡頭改焦：量 focus breathing、失焦造成偵測框變化及 AAT 自動調框；這些不應被當成主體移動。
3. 物體距離不變，轉頭／遮擋／橫移／換主體／改 crop：量錯誤方向與失效判定，不能只收容易的正臉前後走。

解析度正規化只能處理純縮放；zoom／crop／電子防震取景變化另有投影改變。首版可在改變時重置，再決定哪些情況值得補償。

## 4. 運動方向與修焦方向不能直接畫等號

幾何估的是主體深度變化方向；光學修焦需要知道**目前焦平面相對主體的位置**。例如主體持續接近，但鏡頭已先移得太近，當下修正就可能需要往遠端。主體靜止也可能仍嚴重失焦。

因此不能一律用 `幾何方向 × DFD 離焦量絕對值` 下命令。這種做法只有在「最近已確認合焦、主體連續、沒有越峰、時間配對可信」等已驗證條件下，才可能作有限預測。

| 當下證據 | 融合器的行為 |
|---|---|
| 幾何方向可信，最近有光學合焦錨點，DFD 尚不可用 | 提供受限的搜尋方向／下一焦點趨勢，原廠 CDAF 量測確認；不虛構精確步數 |
| 幾何與帶符號 DFD 都可信且時間對齊 | 幾何負責運動趨勢；DFD 更新目前殘餘誤差；將兩者的時間角色分開，避免對同一運動補償兩次 |
| DFD 只有離焦大小、前後符號未定 | 幾何不能普遍補出前後焦；只在合焦錨點與狀態支持時提供方向先驗，否則由原廠已知小位移／CDAF 消除歧義 |
| 幾何與光學修正方向不一致 | 先檢查曝光時間、過衝、呼吸、ROI 與目標變更；不強行多數決或硬套幾何符號 |
| 幾何未知，但光學訊號有效 | 原廠 CDAF／已驗證 DFD 照常工作，避免因沒有臉框而失去一般對焦 |
| 目標切換、來源尺度突變或兩者都不可信 | 使舊幾何／DFD 歷史失效，回原廠取得新合焦錨點 |

幾何估距仍可在**當前主體與鏡頭校準有效**時，提供備援粗目標；與只判方向的版本分開比較。沒有校準時不會阻擋方向研究，也不默默沿用別人的臉尺寸或前一場次的曲線。

## 5. 資料與驗收分開

最低輸出契約（新設計，尚未全實作）：

- 幾何：目標／尺度來源 generation、直接或推算、時間與影像年齡、正規化尺寸、`approach/recede/stationary/unknown`、相對變化率、信心與失效原因。
- 光學：同一目標及 ROI generation、曝光與鏡頭位置、離焦量／峰區間、有號或無號、單位／校準版本、信心與失效原因。
- 融合：最後光學合焦錨點、原廠 state／drive／目標位置、兩種估計的時間關係、採用何種建議及拒絕原因。

**幾何先驗收：**已知主體運動方向的錯誤率、unknown 比例、靜止誤動作率、慢速／反向延遲；不能用 H 峰定義主體接近／遠離的真值。

**DFD 獨立驗收：**獨立清晰度基準下的峰區間／離焦誤差、前後歧義、拒絕比例，以及是否比簡單 CDAF 梯度多提供可用資訊。

**融合最後驗收：**相同 tracker／ROI 條件下比較原廠、AAT 改進、幾何＋CDAF、DFD＋CDAF、幾何＋DFD＋CDAF；用逐項加入的方式歸因。將首次合焦時間、已有錨點後的追焦延遲、失效後重新取得時間分開；再量清晰度、總行程、反向／拉風箱與錯跟，不能用追焦收益宣稱冷啟動已加速。

## 6. 階段調整

1. **M1** 同時取 face／AAT 原始尺度、AF 採用 ROI、目標與來源切換、H/L、鏡頭位置及時間；EP83 服務這份資料契約。
2. **M2-G（主線）** 把舊幾何抽成獨立方向器，先旁路驗證；與 **M2-A** 的 AAT 尺度／身份品質改進並行。先不要求絕對估距，也不等待 DFD。
3. **M2-D（並行）** 驗證 DFD 能否估離焦量／焦點區間及可信度；成功才提供幾何方向之外的位移資訊。
4. **M3** 先完成「原廠首次合焦→錨點→幾何＋CDAF 追焦→失效重取得」的受限機內版本；DFD 通過後再加入位移估計，分別驗收。
5. **M4／M5** 在實際錄影中擴至自然動態、不同鏡頭與可使用版本；使用者已限定只做 CINE 連續 AF，錄影需求從 M1 即納入。CINE 待機先核對來源，不能代替錄影驗收。運算全部在機內，USB 僅供開發觀測。
