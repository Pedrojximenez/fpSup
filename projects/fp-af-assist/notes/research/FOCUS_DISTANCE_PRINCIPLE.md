# 對焦位置 ↔ 距離 換算原理(SIGMA fp,從韌體反編譯還原)

給實作 AF 的人:這份只講**原理與數學**,任何語言都能照著寫。不依賴任何工具。
來源:韌體 `FUN_c033e0d8`(`LmountFocusL::v21`)+ `FUN_c04d0a20`(`XC_Linear.cpp`)。

---

## 1. 一句話原理

> 鏡頭給一組「**對焦位置 ↔ 距離**」的支撐點(離散校準點)。
> 換算 = **把距離取倒數(1/距離),然後在「位置 ↔ 倒數距離」之間做分段線性內插。**

關鍵就是「**在倒數空間內插**」這件事。位置對「距離」不是線性,但位置對「1/距離」接近線性,所以韌體先轉倒數再直線內插。

---

## 2. 為什麼是倒數(1/距離)

光學共軛方程:`1/焦距 = 1/物距 + 1/像距`。
對焦環移動 ∝ 像距變化,而像距 ∝ `1/物距`(近似)。
所以:

- **對焦位置 ∝ 1/距離**(近似線性)
- 對焦位置 vs 距離本身 → 強非線性(近攝端擠、無限遠端疏)

**推論**:只要工作在 `x = 1/距離`(屈光度)這個座標,位置↔x 幾乎是直線,分段線性就很準。這也是韌體為何用 `1e9 / 距離`(乘 1e9 是為了整數精度,用浮點就直接 `1/距離`)。

---

## 3. 鏡頭給的資料:兩條配對的支撐點陣列

每顆(定焦)鏡頭在資料裡帶 N 個配對點(28mm Art 是 N=19):

```
距離陣列  D[0..N-1]   遞減,單位 mm。 D[0] = 無限遠標記(很大的數,如 1_000_000)
位置陣列  P[0..N-1]   遞增,鏡頭內部對焦位置編碼
```
兩者**同 index 配對**:`D[i]` 這個距離,對應到對焦位置 `P[i]`。

例(28mm Art):
```
D = [1e6(∞), 3232, 1897, 1429, 1115, 950, 812, 714, 600, 550, 516, 453, 414, 378, 352, 333, 314, 293, 278]
P = [4096,   4559, 4907, 5197, 5544, 5834, 6182, 6530, 7109, 7457, 7747, 8442, 9022, 9717, 10355, 10934, 11630, 12557, 13369]
```
(近攝端 278mm ↔ 位置 13369;無限遠 ↔ 位置 4096。位置越大 = 對焦越近。)

---

## 4. 演算法(純邏輯,任何語言可寫)

先定義每個支撐點的倒數距離:`R[i] = 1 / D[i]`(D[0]=∞ → R[0]≈0)。

### 位置 → 距離
```
1. 夾限:pos 限制在 [P[0], P[N-1]]
2. 找 bracket:找 i 使得 P[i] <= pos <= P[i+1]
3. 位置線性比例:t = (pos - P[i]) / (P[i+1] - P[i])
4. 在倒數空間內插:r = R[i] + (R[i+1] - R[i]) * t
5. 距離 = 1 / r          (r==0 → 無限遠)
```

### 距離 → 位置(反向)
```
1. 夾限:dist 限制在 [D[N-1], D[0]]
2. r = 1 / dist
3. 找 bracket:找 i 使得 R[i] <= r <= R[i+1]   (即距離落在 D[i]~D[i+1] 間)
4. 倒數線性比例:t = (r - R[i]) / (R[i+1] - R[i])
5. 位置 = P[i] + (P[i+1] - P[i]) * t
```

### 內插原語(FUN_c04d0a20 就是這個)
```
linear(x0, x1, y0, y1, x) = y0 + (y1 - y0) * (x - x0) / (x1 - x0)
```
韌體用它,x 是倒數距離、y 是位置(或反過來)。就這麼單純。

---

## 5. 離焦量預測先驗(給 AF 用)

某位置的「每單位位置的屈光度變化」= 局部斜率:
```
slope(pos) = ( 1/dist(pos+δ) − 1/dist(pos−δ) ) / (2δ)
```
這就是「驅動一單位位置,焦點移動多少屈光度」。AF 爬山時拿它把對比斜率換算成該驅動多少 → 一步到位(見 `AF_DESIGN_REFERENCE.md`)。因為在倒數空間,這個斜率在整個行程接近定值,很好用。

---

## 6. ★ 座標層要注意(誠實,別踩坑)

系統裡「位置」有**好幾個不同刻度**,別混用:

| 域 | 範圍(28mm) | 誰用 |
|---|---|---|
| **PTP/GIMBAL focus_pos** | 3168 – 14296 | 你透過 0x9405 讀 / 0x9411 驅動的值 |
| **本表的內部位置 P[]** | 4096 – 13369 | 上面演算法的「位置」 |
| (其他中間域) | 9000–37000 等 | 韌體內部各層,別管 |

**本表演算法用的是「內部位置(4096–13369)」,不是你 PTP 讀到的 focus_pos(3168–14296)。**
兩者是不同刻度,中間差一層(韌體外層 wrapper 的換算,我沒完全靜態解出)。

**實務做法**:PTP focus_pos → 內部位置,這一層**大概率是簡單線性**(scale+offset),
你只要**實機取 1~2 個點**(讀 PTP focus_pos + 該位置對應的表內部位置/距離)就能定出來:
```
內部位置 = focus_pos * a + b     ← 取 2 點解 a, b
```
之後:`PTP focus_pos → (線性) → 內部位置 → (本表倒數內插) → 距離`。

---

## 7. 變焦鏡(2D,擴充用)

定焦鏡:一組 D[]/P[]。
變焦鏡:韌體用 **2D 表**(焦距 × 光圈維度),記錄以 0x128 bytes 為 stride 一筆一筆排,
資料裡 `+0x222c` 旗標 !=0 代表 2D。實作要先依「當前焦距/光圈」在外軸選/內插出一組 D[]/P[],
再跑第 4 節的內插。原理相同,只是多一層外軸內插。

---

## 8. 換算鏈總覽
```
PTP focus_pos (3168–14296)
   │  線性(實機標 1~2 點:內部位置 = focus_pos·a + b)
   ▼
內部對焦位置 P 域 (4096–13369)
   │  ★ 本文第 4 節:倒數空間分段線性內插(D[]/P[] 支撐點)
   ▼
距離 (mm)
```
非線性全在「倒數內插」那段;前面 focus_pos→內部位置 是線性換刻度。

> 資料(D[]/P[])怎麼從記憶體 dump 抽:見 `RAW_GRAB.md`/`SOP_LENS_EXTRACT.md` 的 mem-save 流程,
> lens_data 指標 → `+0x3488`=點數 N、`+0x348c`=距離陣列、`+0x3564`=位置陣列。
