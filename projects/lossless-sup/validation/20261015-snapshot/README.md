# 2026-10-15 引擎暫存器快照：整段只開一次引擎（成功）

## 原因

原廠送引擎 `C062FFF8` 把設定 **OR** 進暫存器（`300D0040 |= 格式`、`44/48 |= 寬高`、`4C/50/54` 切塊、`6C/70`、
`78 |= 來源位址`、`7C |= 輸出位址`、`84 |= 表位址`…），假設它們是 0——這由 close→open 的斷電重開保證。
之前的輕量重開都沒清這些暫存器：輸出緩衝 A/B 交替，兩幀位址 OR 在一起變成錯的位址 → 每隔一幀 pattern 4 拒絕、eoi+tiles 暴增。

## 做法（實驗建置 `--engine-snapshot`，`FPL_ENGINE_SNAPSHOT`；一般建置不變 = `4057e2ae…`）

每段第一個工作照原廠完整 open，open 後立刻讀 `300D0040..300D0090`（21 字）存成快照；之後每個工作不 close/open，
先把快照寫回這 21 字，再照原廠 submit／reset／start。拒絕、錯誤、放棄、送引擎失敗 → close 並作廢快照（下一個重新 open）。
段落結束（停錄收尾）與進入回放時 close。快照由兩個通道共用（同一顆引擎）。`engine_mode`（USB 寫入）切換開關做 A/B。

建置：實驗＋診斷 `build-snap` = `57c3ea73…`。離線：codec_job、frame_hold、card_emulation、v3 全過。
