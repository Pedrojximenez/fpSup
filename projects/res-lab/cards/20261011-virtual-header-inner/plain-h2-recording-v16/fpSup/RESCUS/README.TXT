RES-Lab applies completed edits through Virtual RCD in memory without saving. SAVE exports named RCD files here (1-7 A-Z/0-9 characters; blank uses LABnnn). Existing names are never overwritten. RES-CUSTOM settings manage which files are enabled. Restart after changing the enable list to update Resolution and QS. With Virtual RCD, five file slots are available; disable one first if full.
