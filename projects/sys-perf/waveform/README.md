# waveform:亮度波形(HistogramDrawerWaveForm)加速(2026-10-20,離線)

上機實測：波形開(`SetDisplayBrightnessLevel=1`)多吃約 25% CPU(`projects/sys-perf/README.md` 實測 1、3)。
本模組換掉整個波形繪製方法，**輸出與 C0529D10 呼叫序列和原廠逐位元相同**。沒上機、沒寫卡、沒 commit。

## 原廠結構 [靜]

- 方法 `C05A3728(this, ctx, img)`,經三個 vtable 槽呼叫:`0xC2DF8F4C`、`0xC2DF8FE4`、`0xC2DF9220`(全是 `C05A3728`)。
  1. `C0529D98(ctx, this+8, [this+0x18])`
  2. `memcpy(tab, 0xC2DF8954, 0x528)`(其實會被下一步整個蓋掉)
  3. `C05A34B8(this, img, tab)`:抽樣。`tab[i]=(i*step)>>16`(330 欄);V=`[this+0x74]` 列，每列從 YUV422 影像(`C0023030` 把實體位址轉成 0xC… 快取別名)
     取 330 個亮度位元組寫到 `[this+0x30]`(V×330)。`[img+0x1c]==0` 回 0。
  4. 回非 0 才 `C05A35A0(this, ctx, tab)`:先用 VFP 算「顯示列→亮度格」表(`tab[y]=u32(y*(V-1)/(H-1))`),
     然後每個螢幕欄(W=`[this+0x24]`):`C04D10D8` 清 256 格計數 → 數這一欄 V 個樣本 → 每個顯示列 y(H=`[this+0x28]`)
     若 `hist[tab[y]]` 非 0,找第一個 `thr[j] >= count`(thr=`[this+0x34..0x70]` 16 格),呼叫 `C0529D10(ctx, &pt, j+16)`。
  5. 回傳值固定是 **0x528**(原廠用 r0 調 sp),本版照做。

## 改了什麼

| 部分 | 原廠 | 本版 |
|---|---|---|
| 抽樣內迴圈 | 每樣本 7 指令 | `ldm` 一次 4 個索引，2.75 指令 |
| 計數 | 每樣本 8 指令、單一直方圖(load→store 相依鏈) | 兩個交錯直方圖、無相依鏈 |
| 清計數 | 每欄呼叫 `C04D10D8`,外加每次 1 KB 樣板 memcpy | 內嵌 NEON(只用 q0),樣板 memcpy 省掉(無作用) |
| 找顏色級 | 每個點線性掃 16 格門檻 | 每次呼叫建 memo(計數 ≤ V ≤ 256) |

退回原廠(尾跳 `C05A3728`):enable=0、V 不在 1..256、H > 330(這些情況原廠自己會讀出界)。

## 結果(`python3 -B test_waveform.py`,約 4 分鐘)

- 166 個情境(W 1..500、H 1..330、V 1..256、隨機/全黑/全白/單值/漸層/少數值畫面、門檻排序/亂序/極大值、
  sp ≡ 0 或 4 mod 8、`[img+0x1c]==0`):**C0529D10 呼叫序列(含 pt 內容與顏色)、樣本 buffer(含護欄)、回傳值、
  r4–r11/sp、d8–d31、FPSCR 全與原廠相同，0 失敗**。同一個 rig 連續跑、門檻每次不同(會抓到 memo 沒重設)。
- fallback 5 種(V=0/257/1000、H=331、enable=0):確認原封交給 `C05A3728`、計數器 +1。
- `--mutate`:7/7 抓到(只用一個直方圖、門檻比較改 ≤、y 差 1、抽樣尾巴少 2、memo 不重設、step+1、奇數尾巴)。
- 指令數(W=330、H=130、V=256、隨機畫面、27,197 個點):原廠 2,238,621 → **1,491,481(×1.50)**。
  抽樣 596,774 → 238,229(×2.5);繪製 1,504,226(含 `C04D10D8` 109,890)→ 1,225,721。
  繪製剩下的大頭是每欄 V+H 的掃描與 27K 次點呼叫本身(每點 `C0529D10`→`C052B098` 不在本模組範圍)。
  實機上還有相依鏈被拆掉的收益，指令數低估了 [推]。

## DrawMgr 裡的 memcpy 12.8% 不是波形的

波形自己每幀只 memcpy 0x528 + 0x400 B(模擬裡兩次合計 774 指令)。上機波形一關 memcpy 就消失，是因為
**沒東西要重畫了**——那是每輪重繪後的整層複製(`C0528BA0`,另一條線)被波形每輪觸發 [推]。
