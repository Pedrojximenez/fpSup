# 三列 CINE 清單 + 唯讀幾何探針

**這份不改變任何錄製結果。** 感光元件模式、picker、RWZM、畫布全部維持原廠。
只做兩件事：把錄影格式清單換成三列，然後在幾何路徑上掛一支唯讀探針。

目的是回答一個問題：**選第三列的時候，送進 `FUN_c043a158` 的幾何是什麼？**
知道了那個值，`rowpatch_v4` 的守衛才能從「無條件覆寫 FHD」改成「只在選中
open gate 那一列時才覆寫」——也就是把 FHD 那一格還給原廠 1080p。

## 三列清單是怎麼塞進 89 bytes 的

原廠清單在 `0xC0F8E7EC`，89 bytes，後面只有 3 bytes 空檔，塞不下第三列。
這個做法是從社群那份 `FP3KMENU.BIN` 裡讀出來的——他們的替換清單也是**剛好
89 bytes**，靠兩件事省出空間：

- **拿掉 `Popup` 欄**。標頭是 `NO,TEXT,IMAGE,Enabled,Enabled2`，解析器是照
  標頭的欄位名讀的，所以少一欄沒問題。省下 6+6+6 = 18 bytes。
- **資料列用裸 `\n`**，標頭仍用 `\r\n`。每列再省 1 byte。

```
原廠  89  <BOM>NO,TEXT,Popup,IMAGE,Enabled,Enabled2\r\n
          1,0313,Popup,blank,1,2\r\n
          2,0314,Popup,blank,1,2\r\n

我們  89  <BOM>NO,TEXT,IMAGE,Enabled,Enabled2\r\n
          1,0313,blank,1,2\n
          2,0314,blank,1,2\n
          3,OG 3032x2012,,1,2\n
```

第三列的 `TEXT` 直接放字面文字而不是字串 id，`IMAGE` 留空。
**標籤上限 12 個字元**（`3,` + 標籤 + `,,1,2` + `\n` = 標籤 + 8 ≤ 20）。

長度完全相同，所以是 **20 個 32-bit 字的原地覆寫**——不用搬表、不用找指標、
不用 cave、不用新資源、不用字型。後面 3 bytes 的 padding 與下一塊清單的 BOM
建置時都驗過沒被動到。

id `0313` / `0314` 維持原廠文字（`UHD 3840x2160` / `FHD 1920x1080`），
因為現在 FHD 那一列真的還是 FHD。

## 探針

`rowprobe.S`，108 bytes，掛在 `0xC043A19C`，跟 `rowpatch_v4` 同一個掛點、
同一條位移指令。差別是**它不改任何東西**，只把每次看到的 `(寬,高)` 去重後記下來：

```
0xC072FA60   count
+0x04        8 筆 × 8 bytes:  key = (w<<16 | h),  selector
```

`dispfit` 一併裝上（`0xC0437ECC`），免得預覽花屏干擾你在選單裡操作。

## 流程

1. 冷開機（USB 拔除），等 `fpMENU!`。
2. 進 CINE，把錄影格式切到 **`OG 3032x2012`**（第三列）。
   - 如果第三列根本沒出現，或選下去被拒絕／跳回，那本身就是結果——
     記下畫面反應，回報即可，不用繼續。
3. 錄一秒。
4. 接 USB：

   ```
   python3 codex/opengate/probelog.py
   ```

5. 再把格式切回 `FHD 1920x1080`、錄一秒、再讀一次，拿到對照。

## 預期與判讀

```
選 FHD        1936 x 1090      ← 原廠基準
選第三列      ????? x ?????    ← 要的就是這個
```

三種可能：

- **出現一組新的幾何** → 最好的結果。把 `rowpatch_v4` 的守衛從
  `1936 x 1090` 改成那一組，第三列就是 open gate、FHD 那一列還是原廠 1080p。
- **還是 1936 x 1090，但 selector 不同** → 守衛改成比對 selector，一樣可行。
- **兩者都相同** → 這一列在幾何路徑上分不出來。那就要往上游找
  `MenuItemMovieRecSize`（`0xC0742204`）的 enum 值。那張表只有兩筆
  （`2→1920x1080`、`3→3840x2160`），緊接著就是 `Invalid MovSize` 哨符字串，
  原地加不了第三筆，得整張搬走——那是另一段工作。

## 限制

- 僅 Ver.5.02。只寫 RAM；移除 `AutoRun.txt` 並完整斷電重開即回原廠。
- hook 生效期間 USB 只能用 direct `mem get` / `mem set`。
- 這份**不會**產生 open gate 素材。要拍 open gate 用 `mode98_autorun/`。
