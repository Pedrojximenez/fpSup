fp 色彩宽容度 → 709 屏幕:SA 与 GA

左边是 fp 各 ISO 的色彩宽容度(12-bit CinemaDNG,以中灰对齐;数据来自 SIGMA 与 Ole Berek《SIGMA fp Rec709 LUT & Operations Guide v3》,SA 与 GA 都用它)。选中的 ISO 100 那一列,每条连线表示那一档显示在 709 屏幕的哪个高度。点其他 ISO 可切换;图表上方的按钮切换 AEL 对比度 0 / +0.2。

怎么调

  1. 按 COLOR,选第 17 列 RAW。
  2. 右侧上下框选曲线:SA(每档等宽)或 GA(对齐中灰)。
  3. 按 AEL 进更多设置,只用两项:对比度(0 / +0.2)与饱和度(0 / +0.2)。清晰度固定 0。

AEL 对比度:最底 1.6 档怎么显示

机身预览信号的色调表只有 2048 格,削波在第 1918 格,最暗能分辨的第 1 格离削波 10.9 档;fp 官方宽容度是 12.5 档,所以最底约 1.6 档(每列颜色较浅的一段)在预览里都挤在第 0 格和第 1 格之间。实测查表不插值,这段只会以噪点疏密出现:信号越低,被噪声推过第 1 格的像素越少。

对比度 0补回 1.6 档

  • 第 0 格固定纯黑,只代表真的被压死。
  • SA:12.5 档按 709 的档距压进屏幕,底部落在液晶黑位;最底 1.6 档以约 11% 的噪点出现。
  • 最底 1.6 档的噪点越暗越稀疏:还看得到点就是有数据,纯黑才是压死。
  • GA:暗部加一段垫脚,预览最暗一格显示 10%(液晶黑位约 6.6%,略高于它才看得见),再接回文档曲线;中灰以上与文档相同。

对比度 +0.2舍去最底 1.6 档

  • SA 只把预览看得到的 10.9 档按 709 档距压进屏幕(每档比对比度 0 宽);最底 1.6 档全黑,看不到。
  • GA 完全按文档 LUT:最暗几档低于液晶黑位,看起来都是黑的,分不出是否压死。

SA 两种对比度都按 709 的档距:对比度 0 装 12.5 档(较密),+0.2 只装 10.9 档(较松)。GA:对比度 0 把暗部垫到看得见,+0.2 完全照文档。两者第 0 格都一律纯黑。

对 CinemaDNG 的影响:没有。对比度只改监看用的色调表,录下的像素数据和元数据完全相同,两种设置拍的档案可以直接互换。

AEL 饱和度:要不要套 fp 校色矩阵

RAW 模式下 AEL 的「饱和度」不是调鲜艳程度,而是选择色彩矩阵。屏幕和录下的 CinemaDNG 用同一个设置,达芬奇解出来的颜色与监看一致。

对 CinemaDNG 的影响:只有 +0.2 会改,而且只改 ColorMatrix 元数据;0 的档案与一般录下的完全相同。传感器像素数据不变;档案里写入与屏幕相同的 ColorMatrix1/2,达芬奇等软件按它把相机 RGB 转成颜色。后期仍可改用别的矩阵或色彩空间转换。

饱和度 0不套矩阵

  • 默认值。直接显示传感器 RGB,与原厂 OFF 相同。
  • CDNG 与一般录下的档案完全相同(原厂 OFF 的 ColorMatrix)。
  • 颜色偏淡、色相不准,适合只看亮度与曝光。

饱和度 +0.2fp 校色矩阵

  • 套用其他色彩模式所用的 fp 校色矩阵(相机 RGB → Rec.709)。
  • CDNG 写入同一组校色 ColorMatrix。
  • 颜色准确、比 0 饱和,适合判断肤色与色彩。
