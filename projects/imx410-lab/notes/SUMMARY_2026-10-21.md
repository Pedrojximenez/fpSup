# IMX410 研究成果整理（2026-10-21）

依使用者研究方針（以能力為主、停止窮舉）改向後的成果。細節在 IMX410_RULES.md 各節；能力狀態在 CAPABILITY_MAP.md；方向在 RESEARCH_DIRECTION.md。
標記：[M] 上機實測、[C] 程式碼、[I] 推論。

## 1. 新確認的能力

| 能力 | 結果 | 節 |
|---|---|---|
| **1000 fps 讀出** | [M] 2×2 快速（donor mode 11，HMAX 330）裁 160 列（3032 寬），VMAX 212 → **1029 fps**；影像位準 = 237.1 + 0.196·VMAX（640→212 誤差 ≤1 DN）→ 每幀都是新曝光 | §47 |
| **幀長規則** | [M] SoC `0x30100020` 就是感光元件幀長（直接寫即生效）；**VMAX_min ≈ 影像列 N + 46 + 2·`0016`**；低於門檻 → 全黑或少送列 | §46、§47 |
| **消隱暫存器** | [M] `0016` = 垂直消隱（每 1 = 2 列）；原廠 1×1 為 35，可降到 2（1×1） | §47 |
| **感光元件內多幀長曝光** | [M] `0007/0008` = 長曝光幀數：曝光 = (0007+1) 幀（2.0×/3.0×/5.0× 實測），中間幀輸出全黑，只讀一次 | §44 |
| **新讀出寬度** | [M] `0001` 未用值：`18` = 5073 寬、`03` = 4016 寬、`01`/`16` = 6064 寬變體；bit 7 無作用 | §43 |

## 2. 新確認的限制

| 項目 | 結果 | 節 |
|---|---|---|
| 線時間下限 | [M] 由 AD 等級鎖死、**與寬度無關**：14-bit ≈ 860（原廠 911）、12-bit 一般 ≈ 430–445、快速 ≈ 330（6064 全寬時約 400） | §42、§45 |
| 半快速 14-bit | [M] 不可行：AD 位數與速度由 `0001` 決定，Family A 換成 12-bit 值仍輸出真 14-bit、同樣在 850 失效 | §42 |
| 一幀多次讀出 / 隔幀雙格式 | [M] `0001` 全 256 值：列數從未加倍、狀態不跳動；`3D/3E` 的「交替」是幀邊界滑動 | §43 |
| PDAF | [M] Sony a7 III ZAF 組整組寫入無作用；**未觸發（非否定）**——使用者判斷同晶片應有此功能 | §41 |

## 3. 推翻的舊結論

| 舊結論 | 更正 | 原因 |
|---|---|---|
| §14「0007/0008 ≠ 0 → 黑幀，只是 SHS 高位元」 | 多幀長曝光；黑幀是抓到累積中的幀 | 只抓單幀、沒看序列 |
| §15「VMAX 1300 → 167 fps、幀完整」及其他用 `frame_count` 量的幀率 | 只是幀計數；AE 用 `0x30100048[26:16]` 開多幀曝光把亮度補平 → **成像幀率未驗證**（待重驗，RESEARCH_DIRECTION 第 1 項） | 沒鎖增益/SHS、沒固定快門 |
| §46 初版「SoC VMAX 不是感光元件幀時序」 | 是；誤判同上 | 同上 |

**量幀率的標準方法（之後一律照做）**：IMXB 代換 SHS=4 + 鎖增益（003D–0040）+ `imager fixed_shutter 1 100`，
掃 VMAX，影像位準必須對 VMAX 呈直線；接收端列數（0x301005D8）不得少於設定。只看 `frame_count` 不算數。

## 4. 方法與工具（本日新增，projects/imx410-lab/）
- `zaf.py` / `offline/zaf_eval.py`：成組寫入 + 稀疏像素/週期搜尋。
- `half14.py`（`--word`、`--rxw`）、`ramp14.py`、`offline/half14_eval.py`：線時間下限。
- `sweep0001.py`、`focus0001.py`、`offline/sweep0001_eval.py`：格式全值掃描（每值寫回並確認恢復）。
- `shs2.py`、`shs2seq.py`：IMXB 代換測 0007/0008。
- `vmaxreal.py`（`--rows`、`--sensor`、`--shutter`）、`shszero.py`、`vmaxsrc.py`、`hs11.py`：真實幀長、最小幀長、高速條帶。
- 高幀率下 BUFA0 尾端哨兵要不驗證寫入（>400 fps 時 DMA 先改寫）。
